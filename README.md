# AI-Powered E-Commerce Operations Intelligence System

## Overview

An AI-powered analytics platform for e-commerce businesses that provides:

- Demand Forecasting
- Customer Segmentation
- Anomaly Detection
- AI Business Reports
- Interactive Streamlit Dashboard

## Technologies Used

- Python
- Pandas
- Scikit-Learn
- Prophet
- Streamlit
- Groq API

## Machine Learning Models

### Demand Forecasting
- Prophet

### Customer Segmentation
- K-Means Clustering

### Anomaly Detection
- Isolation Forest
